## Повторение

Скопировать `raw/` и `out/` из закрытого гардероба в `tools/wardrobe/`, установить зависимости.
Затем из `maxi-project`:

```bash
python3 tools/wardrobe/inventory.py
WARDROBE_COMMIT=<точный SHA гардероба> node tools/lab/baseline.mjs
```

Личные исходники, снимки и подробные метрики находятся в игнорируемой `tools/wardrobe/out/`.
Этот коммит не переносит их в публичный проект. Скрипт не перезаписывает завершённую
контрольную версию: для нового сравнения нужно указать другой `OUT`.
