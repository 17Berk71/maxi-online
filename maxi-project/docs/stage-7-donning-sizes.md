# Короткое надевание и несколько размеров

Новый режим записывает 37 кадров последнего участка настоящего расчёта ткани без движения тела: около 1,23 секунды. Ткань появляется за первые 10 кадров. Каждый кадр получает ту же доводку проймы и рукава, что и итоговая сетка. По окончании возвращаются точные позиции, нормали, края и исходная прозрачность материалов. Отключение анимации и системное уменьшение движения сразу переводят вещь в итоговое состояние.

Анимированная примерка пока пересчитывается, поскольку старый кэш хранит только итоговые точки, без кадров. Это увеличивает время расчёта; дальше нужно кэширование кадров отдельно. Короткое оседание отражает работу текущего приближённого решателя, а не доказывает реальные свойства ткани.

Таблицы `sizesT` уже поддерживают самостоятельные мерки каждого размера. На стенде добавлено ручное сравнение футболки шириной 50, 54 и 58 см. Только ширина 54 см подтверждена замером. Другие варианты — демонстрационные выкройки с приблизительными длиной, плечами и рукавом, с явным предупреждением. Они не участвуют в автоматической рекомендации размеров. Это не реальные S/M/L производителя. Для настоящего размерного ряда нужны мерки каждого изделия и правила градации, отдельно для разных фасонов; равномерное масштабирование всей модели недостаточно.

Проверены 18 существующих JS-тестов и прямой расчёт записанных кадров (37 кадров, конечные координаты, отсутствие движения тела). Сборка прошла. Полный сценарий ТРЦ запущен отдельно; результат следует проверить перед слиянием. Опубликованный интерфейс Sites отдельно браузером не проверяется в этом окружении.
